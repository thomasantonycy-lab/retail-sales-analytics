Retail Sales & Customer Behaviour Analysis

Project Overview

This project analyzes real-world online retail transactions to understand sales performance, cancellations, data quality, and customer purchasing behaviour.

The goal is to build an end-to-end data analytics portfolio project using Excel, MySQL, Python, Power BI, and Tableau.

Dataset

Source: UCI Online Retail Dataset

Records: 541,909

Period: December 2010 - December 2011

Industry: Online Retail

Tools

Microsoft Excel - Data exploration and initial cleaning

MySQL - SQL-based business analysis (planned)

Python - Data cleaning and exploratory analysis (planned)

Power BI - Interactive dashboard (planned)

Tableau - Data visualization (planned)

Git & GitHub - Version control and documentation

Initial Findings

Total transaction records: 541,909

Records classified as cancellations: 9,288

Cancellation record rate: 1.71%

The cancellation rate is calculated at the transaction-line level, not the unique-order level.
